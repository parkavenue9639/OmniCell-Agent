# 单细胞预处理

先使用本次 run 明确提供的 dataset artifact，不得从历史文本、文件名或 URI 猜测输入。仅需核验物种、组织、疾病状态或任务类型时使用 `inspect_dataset`；用户只要求方法解释时不读取数据，用户只要求一个明确处理步骤时直接调用对应 Tool，不为了形式完整执行整套预处理。

## 方法选择与边界

- 质量控制阈值依赖测序方案、组织、数据分布和研究目标。细胞或基因过滤会改变分析总体，不能把固定经验阈值描述为普适金标准；未获得用户授权时不要擅自过滤。
- 总量归一化与 `log1p` 用于调整测序深度尺度并稳定表达分布，但不等同于批次校正，也不能消除所有技术或组成偏差。已知数据经过等价处理时避免重复变换。
- 聚类前应确认输入满足 `cluster_cells` 声明的归一化前置条件。前置条件不足时，由 Agent 明确补齐步骤或请用户确认，不能让当前 Tool 隐式扩张目标。
- 推荐的依赖顺序是质量控制、归一化、降维与聚类，但实际只执行用户目标和数据状态所需的最小子集，不把“常见顺序”升级为固定流水线。

每个变换 Tool 都返回新的 dataset artifact；后续调用必须使用最新输出，不能依赖上一次 Tool 调用的容器内 `adata`。验收时核对输入与输出 ArtifactRef、处理前后细胞/基因数量、实际参数和 Tool 返回的状态摘要。不要把内部 Recipe、代码路径或执行容器状态当作用户结果，也不要把执行成功等同于数据质量已经适合所有下游分析。
